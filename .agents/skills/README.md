# 项目开发技能

来源：[mattpocock/skills](https://github.com/mattpocock/skills)，MIT 许可见 [LICENSE.mattpocock.txt](LICENSE.mattpocock.txt)。

安装版本：`4ae2317ddb22b046e26455e4f9c9b3aaaf62212d`。技能及配套参考文件保持上游原文。

用户指定：`grill-with-docs`、`to-spec`、`to-tickets`、`implement`、`code-review`、`retro`。

配套技能：`grilling`、`domain-modeling`、`tdd`、`codebase-design`、`writing-for-agents`；首次配置入口：`setup-matt-pocock-skills`。

首次使用工程流程前，调用 `$setup-matt-pocock-skills`，确定任务存到哪里、领域文档放在哪里。当前仓库已有 `CONTEXT.md`，配置时先核对现有约定与上游 `GLOSSARY.md` 命名。

常用顺序：`grill-with-docs → to-spec → to-tickets → implement → code-review → retro`。小改动可以省略规格或拆单。

Codex 中用 `$技能名` 调用，也可以在消息里明确要求使用该技能。安装后下一轮对话可用。
